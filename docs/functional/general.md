# Sistema de beneficios

## Objetivo:
Permitir que los socios asociados a CeCIT (centro de comercio de Alta Gracia) obtengan beneficios de distinta índole para usar en los negocios asociados al mismo.

`Usuarios:`
- Administradores de CeCIT
- Administradores de negocios
- Usuarios

`Módulos:`
- Auth
- Gestión de Usuarios
- Gestión de Cuentas
- Gestión de Vouchers (Beneficios canjeados por un usuario)
- Gestión de Beneficios publicados
- Gestión de Administradores
- Gestión de Negocios Asociados
